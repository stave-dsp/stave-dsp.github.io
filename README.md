# stave-dsp.github.io

The website for [stave](https://github.com/stave-dsp/stave), served by GitHub Pages at https://stave-dsp.github.io. Plain HTML and CSS, no build step: open `index.html`.

The hero's code is not written here: it is the `stave` crate's own doctested example at the newest release tag, copied in by `python3 scripts/hero.py` (run it after a framework release). CI (`.github/workflows/hero.yml`) fails when the page is behind the newest release.
